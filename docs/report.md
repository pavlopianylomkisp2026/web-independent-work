## 2. Опис проєкту

Цільова аудиторія — студенти, які вивчають веброзробку. Мета — надати навчальні матеріали й відокремити управління контентом від його відображення. WordPress обрано через наявні редактор, REST API, ролі та категорії. Next.js забезпечує окремий React-фронтенд і серверне отримання даних.

## 3. Архітектура та модель

Редактор → WordPress → MariaDB. Next.js → REST API WordPress → сторінка для відвідувача.
Матеріал має ID, назву, slug, текст, короткий опис, дату, статус, автора та категорії. Автор пов’язаний із багатьма матеріалами; матеріали можуть належати кільком категоріям.

Поточний етап використовує адміністратора для початкового налаштування. Ролі автора/редактора та погодження публікацій ще потрібно налаштувати й перевірити.

## Доповнення: реалізовані SEO-заходи

Сайт має окремі title/description для головних і статей, canonical URL, мовні alternates, Open Graph і Twitter Card. Sitemap формується з усіх опублікованих матеріалів WordPress, а не лише поточної сторінки каталогу. Пошукові та відфільтровані сторінки позначені noindex, follow. Robots вказує sitemap і блокує індексацію локальної версії. Публічна адреса задається SITE_URL; доступність зовнішнім пошуковикам перевірятиметься після деплою.
