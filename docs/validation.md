# Перевірка першого етапу — 2026-10-06

- `npm ci --cache /workspace/.npm-cache`: встановлення з lockfile успішне.
- `npm run build`: production-збірка успішна.
- `npm run typecheck`: TypeScript без помилок.
- `npm audit --omit=dev`: відомих вразливостей у production-залежностях не виявлено на момент перевірки.
- `npm run smoke`: 6 функціональних перевірок пройдено з реальною WordPress CMS.
- Повторний `npm run cms:seed` не створив дубль навчальної статті.

Smoke перевіряє існування початкової статті в API, посилання з головної, її текст на фронтенді, HTTP 404 невідомої статті, заборону читання чернеток і заборону анонімного створення матеріалів. WordPress повертає зовнішній HTTP 400 для недозволеного параметра `status=draft`, із вкладеним кодом `rest_forbidden_status`; перевірка перевіряє цей код, а не лише статус.

Не перевірено: візуальний вигляд реальним браузером, публічний деплой, повний цикл редакторського погодження та мультимовність. Це наступні етапи. Docker volumes зберігають дані у поточному середовищі; відновлення в новій cloud-сесії не підтверджене. Setup може відтворити початкову статтю, але не замінює резервну копію майбутнього контенту.

## Етап 2: категорії

Production-збірка та TypeScript успішні. Розширений `smoke` пройшов проти реального WordPress: матеріал своєї категорії показується, матеріали інших категорій виключаються, вибраний фільтр позначено активним, невідома категорія має зрозумілий порожній стан. Базові перевірки статті та захисту також пройшли. Візуальна перевірка браузером залишається невиконаною.

## Етап 3: пошук

Production-збірка успішна. Smoke проти реальної CMS перевірив пошук за текстом матеріалу разом із категорією, збереження параметрів та порожній результат для невідомого запиту. Попередні перевірки категорій і безпеки також пройшли.

## Етап 4: пагінація

Збірка, TypeScript та попередній smoke пройшли. Із двома тимчасовими статтями у хмарній CMS перевірено: 3 картки на першій сторінці, 1 на другій, відсутність повторів, переходи, повідомлення для сторінки 999 та нормалізацію -1 до першої сторінки. Тимчасові статті після перевірки видалено.

## Етап 5: обкладинки

Збірка успішна. Smoke із реальною тестовою обкладинкою перевірив зображення у статті та доступність URL. Додатково перевірено HTML картки, URL картинки та Alt Text із CMS. Тимчасове медіа й прив’язку після перевірки видалено. Візуальний вигляд і обробку помилки завантаження реальним браузером ще не перевірено.
